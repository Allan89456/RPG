# RPG
***
Manage a hero's equipment.

## Installation
***
```
$ cd src/
$ g++ -Wall -Werror -Wshadow classes/Object.hpp classes/Object.cpp
classes/Equipment.hpp classes/Equipment.cpp classes/Weapon.hpp
classes/Weapon.cpp classes/Shield.hpp classes/Shield.cpp classes/Hand.hpp
classes/Hand.cpp classes/Hero.hpp classes/Hero.cpp lib/keyboard.hpp
lib/keyboard.cpp lib/display.hpp lib/display.cpp rpg.cpp -o play
$ ./play
```
